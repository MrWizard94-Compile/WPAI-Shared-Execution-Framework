# WPAI Shared Execution Framework

This project contains the Windows-local MCP probe and the Stage 1 read-only repository health operation. Read `README.md`, `work/wpai-exec/README.md`, and the applicable stage report for commands, scope and acceptance evidence.

Use the `wpai-constitution` skill. The [canonical Constitution](https://github.com/MrWizard94-Compile/Agents-Constitution) supplies the binding source from its verified accepted `main` at invocation start. The initial publication used v6.24.0 at `0adf5ecee5f7f96ce3749944dc097a003731a6e9`. Follow the frozen skill, always-load set, applicability matrix and SOP. Proposals in this repository do not alter the canonical source.

Preserve the original Stage 0B server and launcher bytes when reproducing recorded tests. The W1 operation is local and read-only. Tool callers cannot choose arbitrary repositories, paths, or commands. Treat approved test evidence as historical, and keep account profiles, credentials and unrelated machine state outside the repository.
