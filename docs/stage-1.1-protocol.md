# Stage 1.1 protocol and source audit

The starting commit was `dea5e311872b9fd2b0bbe021ba8e91547d365147` on clean local `main` and live `origin/main`. The frozen Constitution was v6.24.0 at `0adf5ecee5f7f96ce3749944dc097a003731a6e9`. Its loader and 23 binding files verified against accepted `main`. This milestone excludes constitutional changes.

## Findings before implementation

- The acquisition worker cleared its active slot only after successful response construction and send. An unexpected ordinary exception could strand the slot. Output writes held the state lock, so stdout backpressure could delay cancellation and EOF handling.
- The catalog called the operation local-only despite its authenticated GitHub GETs. Commit subjects used a printable-character filter. Other labels and refs lacked a common display boundary. The existing result shape can carry display-safe values without changing `wpai.repo_health.v1`.
- Both legacy initialize requests require `clientInfo` as well as version and capabilities. The server previously accepted its omission. An unsupported legacy version should receive a supported legacy alternative. `notifications/initialized` completes that sequence. Ping is a legacy method.
- July 2026 discovery and list results require completion, capability or catalog fields, and their cache fields. The server already provided these. The modern call result also needs `resultType: complete`. `serverInfo` inside result `_meta` is recommended on successful modern results and optional in the schema. The base error envelope has no such requirement. Modern `clientInfo` is recommended on requests and optional in the schema. Version and capabilities are required on requests.
- July 2026 cancellation is a notification. Its schema permits a frame with `requestId` and no protocol metadata. The previous server ignored that frame on a modern-only connection. Cancellation and EOF need tests on the actual request path with controlled acquisition and explicit no-response checks.
- Both legacy revisions support structured tool output. Preserve identical values in JSON text and `structuredContent`. The catalog remains a deterministic single operation. Optional extensions, server-initiated requests, other transports and a general JSON Schema engine are outside the advertised application scope.
