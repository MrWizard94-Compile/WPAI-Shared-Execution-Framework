### Codex

Use the pinned noninteractive ephemeral JSONL mode with the same local MCP selection and archived legacy protocol. Static source verifies the runtime is embedded and the directly configured MCP process is its local launcher target. Verify private scratch settings are applied and any ordinary or managed configuration is respected according to policy. Managed policy takes precedence over the test. A future supported isolated account mechanism is required. The prior credential reference is excluded from preparation and recovery.

- **Normal.** Record the provider root, the actual configured MCP process and any independent fixture process. Require matched result, root completion, server-side read EOF and return-path terminal read, each attributable to its actual writer close. Record real exit codes, provider and any fixture job accounting, and observer finalization. A source-expected direct termination-before-EOF is a witnessed lifecycle failure. For a split route, record the provider-owned relay exit, then an independently controlled server writer close and server exit. Label the finding as split-route qualification.
- **Forced.** After the verified tool reply, a separate controller forces only the preselected owned target job while the relevant MCP route remains open. Require a decision and cause record, retained identities and codes for root, actual target and any separate fixture, attributed closure in both directions, job accounting and a finalized witness. A provider kill on the split route must leave separate evidence of the intentionally cleaned-up fixture. Record absent receipts explicitly.
- **Stop and recover.** Stop if containment falls back without full process coverage, another config wins, the root cannot be identified, or an isolated credential mechanism is absent. Close only the owned endpoints and settle the controlled jobs. Retain artifacts before removing the newly created state.

### Antigravity

Use one disposable Python driver, the pinned serving process, one ACP 1 session and one session-local stdio MCP registration using the archived MCP dialect. No editor and no process-per-session override in this route. Limit the driver's host methods to the synthetic workspace and scoped allow-once for the exact tool. First prove the effective ordinary settings/source exclusion and nonmutating account state with version-matched evidence. If choosing a separate-process option or a substitute account method, require a separate documented route review.

- **Normal.** Obtain the synthetic reply, request the supported session completion and observe ACP terminal events. Record driver, serving process, any separate worker and actual server identities. Require actual fixture read EOF, return terminal read, actor closes and all real exit codes under proven accounting. Where the ACP stream only reports a summary, use matching result bytes from the independently observed MCP return path and retain the disclosure. ACP completion alone is insufficient.
- **Forced.** After the verified reply, terminate the previously bound job while MCP is open, from the external controller. Bind the loss of ACP and the separate loss or orderly close of MCP to their actual actors. Require job accounting for the root, any worker and the server, plus witness finalization. An unknown worker cannot be silently excluded from the case.
- **Stop and recover.** Stop on unknown ownership, unexpected settings load, an account or host-method prompt, unscoped tool access, or absent EOF evidence. Close owned ACP endpoints and settle the jobs before removing only the disposable state. Do not change any global server registration.
